# Histórico de versões

## 0.1.0-alpha.1 (versionCode 1) — 2026-10-13

- Projeto Kotlin Android criado do zero, sem dependências de interface externas.
- Um APK com modos Monitorado e Controle.
- Leitura de bateria, temperatura, tensão e correntes.
- Captura autorizada de notificações e SMS novos opcionais.
- Protocolo TCP criptografado AES-256-GCM para Wi-Fi/VPN.
- Keystore, pareamento por chave, revogação, serviço foreground visível.
- Workflow GitHub Actions para testes e APK Debug.
